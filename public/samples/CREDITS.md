# Mi-Flow sound library

Mi-Flow ships 326 sounds. Every one comes from a source released under CC0 1.0, The Unlicense, or an explicit public-domain dedication, verified from the license file inside each source repository. No credit is required, but here is where they came from.

Each sound was converted to mono 32 kHz 16-bit WAV, trimmed, normalized, and (for sustained sounds) given a crossfaded loop region. `library.json` lists every file with its name, category, recorded pitch and source.
